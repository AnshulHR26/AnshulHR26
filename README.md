## 🚀 Featured Project

### ✅ [TaskSync](https://github.com/AnshulHR26/tasksync) — Real-time full-stack task manager

**[🌐 Live Demo](https://daily-tasks-onb4.onrender.com)** · **[💻 Code](https://github.com/AnshulHR26/tasksync)** · **[📘 Setup Guide](https://github.com/AnshulHR26/tasksync/blob/main/SETUP.md)**

What I built:

- **REST API with FastAPI + PostgreSQL** (SQLAlchemy 2) — tasks with priorities, due dates, search, filters and pagination
- **Secure authentication** — bcrypt password hashing, JWT tokens (OAuth2), rate limiting against brute-force logins
- **Real-time sync** across devices with WebSockets — each user only receives their own updates
- **Installable phone app (PWA)** with light/dark mode, built in plain HTML, CSS and JavaScript
- **Cloud deployment** on Render with a one-click Blueprint and managed PostgreSQL
